# ポモドーロタイマー 段階的実装計画

`features.md` および `architecture.md` をもとに、動作確認しながら進められる粒度でフェーズを設計しました。

---

## Phase 1 : プロジェクト基盤の構築

**目標**：Flask が起動し、ブラウザでページが表示される状態にする

### タスク
- [x] `requirements.txt` の作成（`flask` のみ）
- [x] `app.py` の骨格実装（`/` エンドポイント、`index.html` 返却）
- [x] `templates/index.html` の雛形作成（タイトルのみ表示）
- [x] `static/css/style.css` の空ファイル配置
- [x] `static/js/timer.js` の空ファイル配置
- [x] Flask 開発サーバーで起動確認

### 完了条件
`python app.py` を実行し、ブラウザで `http://localhost:5000` が表示される。

---

## Phase 2 : UIレイアウトの実装

**目標**：UIモック相当のレイアウト・配色が静的HTMLで再現できる状態にする

### タスク
- [x] `index.html` にページ全体の構造を実装
  - ヘッダー（タイトル「ポモドーロタイマー」・ウィンドウ操作風ボタン）
  - フェーズ表示ラベル（「作業中」）
  - 円形プログレスバー領域（SVG）
  - タイマー表示（`MM:SS` テキスト）
  - 開始 / リセットボタン
  - 今日の進捗パネル（完了数・集中時間）
- [x] `style.css` に配色・レイアウトを実装
  - 背景：紫系グラデーション
  - カード：白・角丸・シャドウ
  - ボタン：塗りつぶし（開始）／アウトライン（リセット）
  - 進捗パネル：薄いグレー背景・2カラム

### 完了条件
JS なしでモックに近い見た目がブラウザで確認できる。

---

## Phase 3 : 円形プログレスバーの実装

**目標**：SVG アニメーションで円弧が正しく描画・更新できる状態にする

### タスク
- [x] `index.html` に SVG 要素（背景円弧・進捗円弧）を組み込む
- [x] `timer.js` に `setDashOffset(percent)` 関数を実装
  - `stroke-dasharray` / `stroke-dashoffset` で進捗を表現
- [x] ブラウザのコンソールから手動で関数を呼び出して描画確認

### 完了条件
コンソールで `setDashOffset(50)` などを実行すると円弧が正しく変化する。

---

## Phase 4 : タイマーロジックの実装

**目標**：開始・一時停止・リセットが動作するカウントダウンタイマーが完成する

### タスク
- [x] `timer.js` にカウントダウン処理を実装
  - `startTimer()` / `pauseTimer()` / `resetTimer()`
  - `setInterval` による毎秒更新
  - 残り時間を `MM:SS` 形式で DOM に反映
- [x] 開始ボタンのトグル動作（開始 ↔ 一時停止）を実装
- [x] リセットボタンのクリックで現在フェーズの初期値に戻す処理を実装
- [x] 円形プログレスバーとタイマーを連動させる

### 完了条件
開始・一時停止・リセットが正しく動作し、円弧がリアルタイムに変化する。

---

## Phase 5 : フェーズ管理の実装

**目標**：作業 → 休憩 → 作業のサイクルが自動で切り替わる

### タスク
- [x] フェーズ定義（作業25分 / 短い休憩5分 / 長い休憩15分）を定数で管理
- [x] タイマー終了時に次フェーズへ自動遷移する処理を実装
- [x] 4セッション完了後に長い休憩へ切り替えるロジックを実装
- [x] フェーズ名ラベルの表示更新
- [x] フェーズ切替時に円弧の色を変更（作業中：青紫 / 休憩中：緑系）

### 完了条件
タイマーを動かすとフェーズが自動遷移し、4セッション後に長い休憩になる。

---

## Phase 6 : バックエンド API とデータ永続化の実装

**目標**：セッション完了が SQLite に記録され、今日の進捗が取得できる

### タスク
- [x] `app.py` に SQLite 初期化処理を実装（`sessions` テーブルの自動作成）
- [x] `POST /api/session` エンドポイントの実装（レコード挿入）
- [x] `GET /api/today` エンドポイントの実装（当日の完了数・合計時間を集計）
- [x] `timer.js` からセッション完了時に `fetch()` で API を呼び出す処理を実装
- [x] API レスポンスを受けて進捗パネルの DOM を更新する処理を実装

### 完了条件
セッション完了後に進捗パネルの数値が更新され、再読み込み後も値が保持される。

---

## Phase 7 : ブラウザ通知の実装

**目標**：タイマー完了時にブラウザ通知が表示される

### タスク
- [x] ページロード時に `Notification.requestPermission()` を呼び出す
- [x] タイマー完了時に `new Notification(...)` で通知を送信する
- [ ] 通知が拒否された場合のフォールバック（UI上の表示変化など）を実装

### 完了条件
タイマー完了時にブラウザ通知が表示される（許可済みの場合）。

---

## Phase 8 : 結合確認・最終調整

**目標**：全機能が連携し、モックに近い完成形になる

### タスク
- [x] 全フェーズを通した動作確認（開始 → 完了 → 休憩 → 繰り返し）
- [x] 進捗データの表示・保存が正しく動作することを確認
- [x] UI の細部調整（余白・フォントサイズ・アニメーション速度）
- [x] エラーハンドリングの確認（API 失敗時・通知拒否時）

### 完了条件
一連のポモドーロサイクルが問題なく動作し、アプリとして利用できる状態になる。
